# Kecebong

Kecebong is a mobile/web news application built using Ionic Angular. This application allows users to read news, search for news, browse news by category, give ratings, add comments, save favorite news, and add new news or categories.

## Main Features

- User login and registration
- Display news list
- View news details
- Search news by title
- Browse news by category
- Add new news
- Add new categories
- Add comments and comment replies
- Give ratings to news
- Add and remove news from favorites
- View user profile
- Upload news images

## Technologies Used

- Ionic Framework
- Angular
- TypeScript
- Capacitor
- HTML
- SCSS
- PHP REST API backend
- LocalStorage for storing user login data

## Main Pages

Some main pages in this application include:

- `Login`  
  Page for users to log in to the application.

- `Register`  
  Page for users to create a new account.

- `Home`  
  Main page that displays the news list.

- `Category`  
  Page that displays news categories.

- `News Detail`  
  Page that displays complete news content, images, comments, ratings, and favorite button.

- `Favorite`  
  Page that displays saved favorite news.

- `Add News`  
  Page for adding new news.

- `Add Category`  
  Page for adding new categories.

- `Profile`  
  Page that displays user information.

## Installation and Setup

Make sure Node.js and Ionic CLI are installed.
